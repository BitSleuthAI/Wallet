# **App Name**: BitSleuth Wallet

## Core Features:

- Client-Side Encryption: Client-side AES-256 encryption to protect the Bitcoin wallet on the device.
- BIP39 Passphrase Encryption: Enforce BIP39 passphrase encryption on wallet creation.
- PIN/Biometric Login: Provide option to access the wallet via a 4-digit PIN or biometrics for quick and secure access.
- Hardware-Grade Security: Employ second factor authentication (2FA) using FIDO-certified security keys.
- Private Key Control: Ensure private keys are created and stored locally and are not transmitted to any server.
- Certificate Pinning: Use certificate pinning to prevent HTTPS impersonation attacks.
- Tor/VPN Support: Provide built-in support for Tor and VPN, enabling users to route transactions through anonymous IP addresses.
- Bitcoin Transactions: Send and receive bitcoin.
- QR Code Support: Support for QR code scanning for easy address sharing and payment requests.

## Style Guidelines:

- Primary color: Heliotrope (#BF5FFF) for security and trust.
- Background color: Cod Gray (#1A1A1A) for a modern and secure feel.
- Accent color: Bleached Cedar (#362342) for interactive elements and highlights.
- Font: 'Inter', a grotesque-style sans-serif, provides a modern and neutral look suitable for clear and concise information presentation.
- Implement a modular layout with clear visual hierarchy, making it easy for users to understand their wallet information and navigate the app.
- Mobile-first design with a clean and intuitive layout, ensuring a seamless user experience across devices.
- Minimalist vector icons that clearly represent different aspects of Bitcoin transactions and wallet security. A thin line style would be ideal.
- Incorporate subtle, non-intrusive animations for transitions and loading states to improve user experience without distracting from the app's core functionality.
